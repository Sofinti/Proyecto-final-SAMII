TRABAJAR EN RAMAS DISTINTAAS.

Crear Rama y posicionarse
GIT SWITCH -C NOMBRE DE LA RAMA

para cambiar entre ramas es unicamente

git switch nombre de la rama

JAMAS, NUNCA, POR NADA EN EL MUNDO INCLUSO A NIVEL PROFESIONAL, TRABAJEN SOBRE EL MAIN

Para traer luego los cambios a main:

git switch main

git pull (nombre de la rama que quieren traer)
